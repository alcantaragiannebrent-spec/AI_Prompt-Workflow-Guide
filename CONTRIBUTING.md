# Contributing

Thanks for helping improve the AI Prompt & Workflow Guide.

## Ways to contribute

- Suggest a prompt or workflow that solves a clear developer or learner need.
- Improve clarity, accessibility, examples, or organization.
- Report inaccuracies, broken examples, or unclear instructions.

## Guidelines

- Keep contributions focused on practical technical learning and workflows.
- Include the intended use case and any assumptions or limitations.
- Use generic, non-sensitive examples. Do not include secrets, personal data, or proprietary code.
- Make prompts explicit about constraints and desired output.
- Avoid claiming that AI outputs are guaranteed correct or hallucination-free.
- Check that links work and Markdown renders clearly.

## Submitting a change

1. Open an issue to describe a larger proposed addition or change.
2. For a direct edit, open a pull request with a concise summary and rationale.
3. If relevant, include an example showing how the prompt is used and what a useful response should contain.
